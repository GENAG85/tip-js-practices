## 3. Новая логика ПР4

### 3.1. updateTask

Функция `updateTask(tasks, id, title, priority)`:

- проверяет id и наличие задачи;
- нормализует название через `trim()`;
- проверяет приоритет;
- создаёт новый массив через `map()`;
- меняет только `title` и `priority` выбранной задачи;
- сохраняет её `id` и `completed`;
- не изменяет исходный массив.

### 3.2. validateTaskDraft

`validateTaskDraft(draft, tasks, editingId)` является чистой функцией и не обращается к DOM или `localStorage`.

В режиме создания проверяются:

- id: после `Number()` положительное безопасное целое, не пустое и уникальное;
- title: строка длиной 1–100 после `trim()`;
- priority: строго `low`, `medium` или `high`.

В режиме редактирования используется `editingId`, а значение id из формы не используется.

### 3.3. localStorage

Реализованы:

- `isValidTaskList`;
- `loadTasks`;
- `saveTasks`;
- `removeSavedTasks`.

Сохранение выполняется в формате:

```json
{
  "version": 1,
  "tasks": []
}
```

Ключи общего и индивидуального наборов различаются:

- `tip-js-practice-04:demo`;
- `tip-js-practice-04:variant`.

При повреждённом JSON, неверной версии или некорректной схеме приложение использует независимую копию исходных данных и показывает предупреждение.

## 4. Эксперименты с формой и JSON

1. **Пустое обязательное название.** Нативная HTML-валидация блокирует отправку формы до обработчика `submit`.
2. **Название из пробелов.** `required` считает такую строку непустой, поэтому прикладная проверка выполняет `trim()` и отклоняет пустой результат.
3. **Корректные значения.** `FormData` возвращает обычные значения полей строками; id преобразуется явно через `Number()`.
4. **Чтение localStorage.** `getItem()` возвращает строку, после чего JSON восстанавливается через `JSON.parse()`.
5. **Повреждённый JSON.** `JSON.parse()` выбрасывает исключение, поэтому чтение выполняется внутри `try/catch`.

Для повторения экспериментов открыть `examples/forms-storage.html` через локальный сервер.

1. Сбросить сохранённые данные.
2. Добавить `id = 20`, название `Изучить localStorage`, приоритет `high`.
3. Попробовать добавить повторный `id = 4` — должна появиться ошибка у поля id, список не меняется.
4. Изменить `id = 4`: название `Подготовить форму задач`, приоритет `low`; статус остаётся `false`.
5. Отметить `id = 7` выполненной.
6. Удалить `id = 1`.
7. Перезагрузить страницу — изменения должны восстановиться из `localStorage`.
8. Выполнить сброс — вернуться к `[1, 4, 7, 10]`, ключ `tip-js-practice-04:demo` должен исчезнуть.
