## 4. Модель данных и функции

Каждая задача представлена объектом со следующими полями:

- `id` — положительное безопасное целое число;
- `title` — строка длиной от 1 до 100 символов после `trim()`;
- `completed` — логическое значение;
- `priority` — одно из значений `low`, `medium`, `high`.

При создании новой задачи `completed` всегда равно `false`, а приоритет по умолчанию равен `medium`.

Распределение ответственности между файлами:

- `src/data.js` хранит общий набор задач и данные варианта 8;
- `src/task-service.js` содержит девять функций для создания, чтения и изменения данных;
- `src/main.js` содержит общий и индивидуальный демонстрационные сценарии;
- `checks.js` проверяет функции с помощью `node:assert/strict`;
- `examples/functions-and-references.js` содержит шесть учебных экспериментов.

Основные функции модуля:

| Функция | Результат |
|---|---|
| `createTask` | `{ ok: true, task }` либо `{ ok: false, error }` |
| `findTaskById` | Найденный объект задачи либо `undefined` |
| `getPendingTasks` | Новый массив невыполненных задач |
| `getTaskTitles` | Новый массив названий |
| `getTaskStats` | `{ total, completed, pending, progress }` |
| `addTask` | `{ ok: true, tasks }` либо `{ ok: false, error }` |
| `setTaskCompleted` | `{ ok: true, tasks }` либо `{ ok: false, error }` |
| `renameTask` | `{ ok: true, tasks }` либо `{ ok: false, error }` |
| `removeTask` | `{ ok: true, tasks }` либо `{ ok: false, error }` |

**Почему id не равен индексу:** индекс показывает позицию элемента в текущем массиве, а `id` является постоянным идентификатором записи. После удаления элемента индексы могут измениться, а `id` остальных задач остаются прежними.

**Почему getTaskStats возвращает число, а не строку с процентом:** расчётная функция возвращает числовой `progress`, чтобы результат можно было использовать в дальнейших вычислениях. Форматирование через `toFixed(1)` выполняется только в `main.js` при выводе.

**Какие объекты копируются при изменении задачи:** при успешном обновлении создаётся новый массив. Для изменяемой задачи создаётся новый объект через spread, а неизменённые объекты могут повторно использоваться без изменения их свойств.
